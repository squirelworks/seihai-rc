The first release of **seihai-rc**, the Seihai project's Graal Remote Control (RC) client for server staff. This release is command-line only. It is written from scratch in Rust (MIT or Apache-2.0).

## What it does

- **Logging in.** It can log in directly to a game server, or pick a server from the listserver's RC list (`servers`, optionally with `--secure-login`). It uses the gen-5 login (type 6) by default; `--rc classic` uses the 2000 to 2002 login (type 1).
- **The RC session.** It shows the RC chat, joins and leaves (`login`), and sends an empty keepalive (id 162) once a minute.
- **Players** (stage 2), where WHO is an id or an account from the player list:
  - `players list`;
  - messages: `players pm`, `players say` (to everyone) and `players admin-pm`;
  - moving players: `players kick` and `players warp`;
  - a player's or an account's details: `players props` (read, or set with `--set`), `players rights`, `players comments` and `players ban`.
- **Accounts** (stage 3): `accounts list/get/set/add/delete`.
- **NPC Control.** `nc login`, `nc discover`, and list, get, set and delete for NPCs, classes and weapons.
- **The file link** (list, get, put), as a library API that a live level editor calls. There is no `files` command yet.

## Tested with

- Loopback tests against fake game servers, listservers and NPC-servers for every command above.
- Captures from a real 2.22 RC against the seihai-gserver-v2 fork, and seihai-rc itself run live against the fork (see `docs/lab`).

## Not in this release

- **Listing the online RCs moves to v0.2.0.** Real RCs never send id 65. They list RCs through the normal player list, where an RC is a player with an empty level, and v0.2.0 will do the same.
- **Props set** handles max hearts, hearts, gralats, arrows, bombs, glove and AP only.
- **Stage 4 is not started:** server options, folder config, server flags and the file browser.
- **No window yet.**

## Download and run

Pick the archive for your system: Linux x86_64, Windows x86_64, macOS Intel (x86_64) or macOS Apple Silicon (aarch64). The password is read from `SEIHAI_RC_PASSWORD`, never from the command line:

```
export SEIHAI_RC_PASSWORD=...
seihai-rc players list --server 127.0.0.1:14802 --account myrc
```

`seihai-rc --help` lists every command. On macOS, the first start may need right-click → Open, because the build is not signed.
