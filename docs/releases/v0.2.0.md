The second release of **seihai-rc**, the Seihai project's Graal Remote Control (RC) client for server staff. It adds a window (`seihai-rc gui`), a `files` command line, server options, folders and flags, and NC text profiles, and it is built on seihai-core v0.8.0. MIT or Apache-2.0.

## What's new since 0.1.0

- **The window** (`seihai-rc gui`, built with `--features gui`): Players, Accounts, Files, NPC Control and Server tabs. Server-specific tabs reset before another login. The Server Flags window confirms a save even when the server returns the flags in another order.
- **Files from the command line**: `files ls/get/put/mv/rename/rm/rmdir`, and large files over the RC file link.
- **Server options, folders and flags** commands.
- **`rcs list`**: the online RCs from the player list. `--json` output, `*account` nicknames and `--identity`.
- **`players props --set`** takes more prop names, flags and weapons.
- **NPC Control**: editing is bound to the selected target, script saves are confirmed with a read-back, trailing empty fields are kept, and text is encoded per server (NC text profiles, picked from the server's `Server:` line; the seihai-gserver profile doubles quoted backslashes, as seihai-gserver#160 does).
- Wire layouts matched to captures of the archived RC builds: the RC list handshake, ban length, chests, NC scripts, move, class delete and weapon get.
- Built on seihai-core **v0.8.0** (was v0.0.6).
- The release has a `SHA256SUMS` beside the archives.

## Tested with

- Loopback tests against fake game servers, listservers and NPC-servers, against the real seihai-listserver (v0.1.2), and the NC commands against a live loopback seihai-gserver and seihai-npcserver.
- Captures from archived RC builds and live runs against the seihai-gserver-v2 fork (see `docs/lab`).

## Download and run

Pick the archive for your system: Linux x86_64, Windows x86_64, macOS Intel (x86_64) or macOS Apple Silicon (aarch64), and check it against `SHA256SUMS`. Run `seihai-rc --help` for the commands. On macOS, the first start may need right-click → Open, because the build is not signed.
