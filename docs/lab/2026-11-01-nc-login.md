# Lab note: NPC-Control login and framing, 2026-11-01

Client: `seihai-rc` on this branch (`nc login`). No original RC or
NPC-Control binary was run.

Server: a fake NPC-server in `tests/nc_login.rs`, bound on the loopback
address at an ephemeral port. The gserver-v2 lab pack is not in the agent
environment, so this run does not speak to the fork.

What was done: the client sends a type-3 login (`NCL11012`, account,
password, no key byte, no byte after the password) as one plain zlib frame,
then reads the next plain zlib frame.

Before: `seihai-rc` had no NPC-Control socket. An address on the lab NC port
could not be logged into.

After: `NcSession::login` accepts a plain-zlib reply, reports a disconnect
message as a refusal, and treats a link that stays open and silent as
connected. `cargo test` covers those three cases.

Logs: the test binary's stdout from `cargo test --test nc_login`. No pcap.
